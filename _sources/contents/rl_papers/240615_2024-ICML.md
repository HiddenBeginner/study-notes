### FRE: Unsupervised Zero-Shot Reinforcement Learning via Functional Reward Encodings
- Kevin Frans, Seohong Park, Pieter Abbeel, Sergey Levine, *UC Berkeley*
- Keywords: Unsupervised offline RL, followed by zero-shot deployment to a labeled offline RL
- Paper link: [https://arxiv.org/abs/2402.17135](https://arxiv.org/abs/2402.17135)
- Project page: [https://github.com/kvfrans/fre](https://github.com/kvfrans/fre)

**Summary**
- During the unsupervised offline RL phase, it learns Functional Reward Encoding (FRE), which is a Transformer-based encoder
that takes as a set of (state, action) pairs from an offline dataset and predicts their rewards. 
- Here, reward functions are sampled from the one of goal-condition reward, random linear reward, and random MLP reward.
- **Strength:** It requires very small number of $(s, r)$ pairs (specifically 32 pairs) to find the task vector, whereas prior methods (Forward-Backward method or Successor Features) required more than thousands pairs (specifically 5120 pairs).

### Do's and Don'ts: Learning Desirable Skills with Instruction Videos


<center>
<video class="center-block" width="100%" autoplay="" loop="" muted="" playsinline="" width="500px">
    <source src="https://mynsng.github.io/dodont/img/DoDont_Quadruped.mp4" type="video/mp4">
</video>
</center>

<center>Video from the author's project page</center>

- Hyunseung Kim, Byungkun Lee, Hojoon Lee, Dongyoon Hwang, Donghu Kim, and Jaegul Choo, *KAIST*
- Keywords: Learning human intention from action-free videos, followed by online unsupervised skill discovery
- Paper link: [https://arxiv.org/abs/2406.00324](https://arxiv.org/abs/2406.00324)
- Project page: [https://mynsng.github.io/dodont/](https://mynsng.github.io/dodont/)

**Summary**
- **Motivation:** Online unsupervised skill discovery (USD) agent without any human demonstration may learn unsafe behaviors. This paper propose a way to inject human intention using action-free videos before online USD phase.
- For video learning phase, this paper tries to learn an instruction network from action-free videos. 
- Here, the instruction network $\hat{p}_\psi(s, s')$ tries to predict whether a given pair of two states $(s, s')$ is a desired pair or not. 
- After that, for online USD phase based on METRA algorithm, the instruction network is used to provide a distance between two states. 
- Here, if two states have a high value of the instruction network, two states are regarded desirable so that provided with METRA's intrinsic reward with a more weight: 

$$r_t = \hat{p}_\psi(s_t, s_{t+1}) (\phi(s_{t+1}) - \phi(s_t))^\top z$$

- **Strength:** Only eight videos are enough to inject human intention into the online USD agent.
